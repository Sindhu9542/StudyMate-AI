# StudyMate AI 📚
StudyMate AI is an AI-powered study assistant designed to help students understand topics, organize their study plans, and track their learning progress.
## Features
- **AI Topic Summarizer:** Explains study topics in simple English using AI.
- **Study Timetable:** Helps students organize their study schedule.
- **Previous Study Plans:** View previously created study plans.
- **Dashboard:** Displays study information and progress.
- **Progress Tracker:** Helps students monitor their learning.
## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Groq AI API
## How to Run
1. Clone or download this repository.
2. Open the project in VS Code.
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Create a `.env` file in the project folder and add your Groq API key:
   ```env
   GROQ_API_KEY=your_groq_api_key
   ```
5. Start the backend:
   ```bash
   npm start
   ```
6. Open the frontend using VS Code Live Server.
## Project Purpose
The goal of StudyMate AI is to make studying easier by providing simple explanations, study planning, and learning progress tracking in one place.
